# Home Assistant Voice: Preview Edition (Brendan's Fork)

This is a forked repo of the ESPHome source code of the [Home Assistant Voice: Preview Edition](https://www.home-assistant.io/voice-pe/).

See [the documentation](https://voice-pe.home-assistant.io/) for set up and troubleshooting.

If you need to re-install the firmware, [use this installer](https://esphome.github.io/home-assistant-voice-pe/).

## About this fork

This fork includes [changes by Rob Meades](https://github.com/RobMeades/home-assistant-voice-pe) to support using custom wake words, along with other personal changes.
